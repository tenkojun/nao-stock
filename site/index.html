Why

왜 만들었나

아버지는 매달 남는 돈으로 주식을 사십니다. 한 달에 열 번쯤 사고, 한두 번 파십니다. 떨어지면 더 사서 평단을 낮추는 습관이 있고, 1개월에서 1년쯤 들고 계십니다.

그런 분께 필요한 건 “오를까요, 내릴까요”에 대한 대답이 아니었습니다. 지금 내 계좌가 한쪽으로 쏠려 있지는 않은지, 이번 달 여윳돈을 어떻게 나눌지, 세금과 수수료를 빼면 실제로 얼마가 남는지 — 확실하게 계산할 수 있는 것들이었습니다.

그래서 이 프로그램은 추천하지 않습니다.
대신 정확하게 계산하고, 빠짐없이 기록합니다.

Scope

하는 일 / 하지 않는 일

합니다 — 계산과 기록

  • 이번 달 여윳돈 배분 계산
  • 계좌 쏠림·집중도 진단
  • 세금·수수료·호가 스프레드 왕복비용
  • 변동성·분산 계산
  • 매매 이유와 계획 기록
  • 지금 가격의 위치(고점·이동평균 대비)
  • 재무 상태·투자자별 수급 표시

하지 않습니다 — 예측

  • 오를지 내릴지 맞히기
  • 매수·매도 추천
  • 목표가·확률·등급 제시
  • 자동매매

한국 대형주로 직접 검증해 봤지만, 비용을 빼고 나면 통계적으로 유의한 가격 예측 신호를 찾지 못했습니다. 그래서 그 자리를 비워 두었습니다.

Evidence

검증을 어떻게 했나

신호를 넣기 전에 통과해야 하는 절차를 먼저 만들었고, 결과가 나쁘면 기능을 뺐습니다.

항목방법
예측력 측정횡단면 Rank IC · Newey–West t (lag = 예측지평)
신뢰구간블록 부트스트랩 · 순열검정
다중검정 보정Benjamini–Hochberg FDR · Deflated Sharpe Ratio
표본 분리70 / 30 홀드아웃
생존편향 제거KRX 시점정합(point-in-time) 유니버스 · 상장폐지 수익률 반영
비용 반영2026년 거래세(매도 0.20%) + 호가단위 스프레드, 유동성 등급별
0보정 후 통과한 신호
250검증 종목
8년표본 기간
0.71이 표본으로 탐지
가능한 최소 연 샤프

유효검정수 40·20 어느 기준으로도 통과한 신호가 없었고, Deflated Sharpe도 두 전략 모두 탈락했습니다. 8년 표본으로는 연 샤프 0.71 이상만 탐지 가능하다는 사전 검토와 일치합니다.

발견한 것도 그대로 적어 둡니다. 60일 신고가 근접 지표는 상장폐지 종목을 포함하면 t=4.3으로 강력해 보이지만, 생존 종목만 보면 t≈0입니다. 죽어가는 종목이 만들어낸 착시였습니다.

Install

설치

git clone https://github.com/tenkojun/nao-stock.git
cd nao-stock
pip install flask numpy requests pandas finance-datareader pywebview

나오주식_실행.bat을 한 번 실행하면 필요한 라이브러리를 설치하고 바탕화면에 아이콘을 만들어 줍니다. 다음부터는 아이콘만 누르면 됩니다. 주소창도, 탭도, 검은 명령창도 뜨지 않는 자체 창으로 열립니다.

pythonw 나오주식.pyw     # 프로그램 창으로 실행
python server.py         # 개발용(브라우저, 자동 리로드)
python tools/check.py    # 배포 전 점검

시세를 보려면 한국투자증권 OpenAPI 키가 필요합니다. 프로그램의 설정 → API 연결에서 넣고 저장할 수 있습니다. 키가 없어도 화면은 합성 데이터로 동작합니다.
